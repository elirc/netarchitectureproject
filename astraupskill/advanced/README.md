# Advanced meeting-invariant engineering

Seven chapters extend the original interval course with command/value-object/aggregate diagrams, boundary worksheets, a disposable lab that compiles real domain source, reflection diagnostics, an independent rule exercise, separate solutions, and a capstone rubric. No application behavior is changed.
